# Line Follower Robot – NYXTeam

<!-- ![Line Follower Robot](https://img.shields.io/badge/Team-NYXTeam-blue)   -->

## 🔎Descriere
Acesta este proiectul nostru de **robot de urmărit linie**, realizat de echipa **NYX-Team**. Robotul este capabil să detecteze și să urmeze o linie trasată, folosind senzori și algoritmi de control, atat interni cat si externi. Proiectul are scop castigarea concursului de robotica a celor de la **roboTec**, astfel desmonstrand capacitatea noastra de munca.

## 📑Caracteristici
- Urmărirea liniei cu precizie pe trasee drepte și curbate;
- Ajustarea vitezei motoarelor în funcție de deviația de la linie;
- Posibilitate de extindere cu funcționalități suplimentare (ex. Control-Web).  

## 📟Componente hardware
- Microcontroler: Arduino UNO R4 Wifi;
- Senzori de linie construiti din 8 senzori de inflarosu;
- Motoare electrice cu micro metal 50:1 HPCB cu (Perii De Carbon);
- Șasiu robot printat la imprimanta 3D, model **PROPRIU**;
- Modul de alimentare se face cu ajutorul unei bateri de litiu de 7.5V si 2.2mA.

## 📝Instrucțiuni de utilizare
1. Conectați senzorii și motoarele conform schemei din `/hardware`.  
2. Încărcați codul sursă din `/software` pe microcontroler.  
3. Porniți robotul pe traseul cu linie trasată pe sol.  
4. Ajustați viteza și pragurile senzorilor dacă este necesar pentru performanță optimă.
